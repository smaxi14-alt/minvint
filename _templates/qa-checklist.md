# QA 검수 체크리스트

> QA 에이전트 또는 최종 발행자가 콘텐츠 발행 전 반드시 확인한다.
> 모든 항목 PASS 확인 후 배포 에이전트에 인계한다.

---

## 기본 정보

```
콘텐츠명:
시리즈명:
검수 일시:
검수자:
```

---

## 1. 브랜드 규칙

- [ ] 얼굴·인물 사진 없음 (이미지 파일 직접 확인)
- [ ] 과장 표현 없음: "최고", "완벽", "1등", "꼭 하셔야", "무조건"
- [ ] 구체적 수치·데이터 1개 이상 포함
- [ ] 신규 가입 유도 메시지 아님 (기존 증권 진단·절감이 핵심)
- [ ] 특정 보험사 상품 직접 홍보 없음
- [ ] 감성·공감만 있고 데이터 없는 단락 없음
- [ ] "더 싼 상품" 대신 "당신에게 맞는 설계" 프레임 유지

---

## 2. 수치·팩트 검증

- [ ] Before/After 수치가 슬라이드 간 일관성 있음 (78만원 → 56만원 등 통일)
- [ ] 고객 사례 사용 시 "실제 고객 사례 (익명)" 표기 있음 (design-style-guide.md Before/After 템플릿 표기와 통일, 2026-07-16)
- [ ] 수치 출처 또는 기준 명기됨 (연도, 기준, 대상)
- [ ] 계산식 정합성 확인 (예: 78-56=22, 22×12=264)

---

## 3. 채널 스펙 (인스타그램 카드뉴스)

- [ ] 슬라이드 수: 5~8장 범위
- [ ] Slide 01: 후킹 숫자 또는 질문 있음
- [ ] 마지막 슬라이드: CTA 명확히 있음
- [ ] CTA 목적지 명확 (카카오톡 채널명 또는 링크)
- [ ] 인스타 캡션: 해시태그 5개 이하 (2025.12.18 Meta 공식 변경 — 과거
      "9개 이상" 기준은 폐기됨. 시리즈 고정 태그 2개 + 회차별 키워드 2~3개)
- [ ] 캡션 내 키워드 자연 포함 ("보험료 절감", "보험증권 진단" 등 — 해시태그보다
      캡션 내 키워드가 검색·분류 신호로 더 중요해짐, 2026 알고리즘 기준)
- [ ] 공유 유도 문구 포함 (예: "배우자에게 공유해보세요" — 2026년부터 공유(sends)가
      저장(saves)보다 강한 순위 신호로 공식 확인됨)
- [ ] 슬라이드 간 색감·폰트 일관성 (nanobanana pro가 프롬프트에 없는 태그라인·
      로고를 임의로 추가하는 경향이 실측 확인됨 — 슬라이드별로 개별 생성 시
      스타일 드리프트가 누적되지 않는지 육안 확인)

---

## 4. 채널 스펙 (블로그·네이버) — 해당 시

- [ ] 분량: 1,500~3,000자
- [ ] 표·그래프 2개 이상 삽입
- [ ] 실제 사례 익명 수치 포함
- [ ] Before/After 비교표 포함
- [ ] 내부 링크 1개 이상

---

## 5. 산출물 파일 관리

- [ ] 저장 경로: `콘텐츠/[시리즈명]/` 하위
- [ ] 파일명 형식: `[시리즈명]-[포맷]-YYYYMM.md`
- [ ] 이미지 파일 저장 완료 (slide01~05.png)
- [ ] 인스타 캡션 파일 포함
