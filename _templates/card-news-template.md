# 카드뉴스 템플릿 — 보험 증권 진단가

> 이 템플릿을 복사해서 새 카드뉴스를 만들 때 사용한다.
> 디자인 스펙은 `_context/design-style-guide.md` 참조.

---

## 메타 정보 (작업 전 작성)

```
시리즈명:
타깃 페르소나: [ ] 김부장(불안형) [ ] 박과장(합리형) [ ] 전체
채널: [ ] 인스타그램 정사각 1080×1080 [ ] 인스타그램 세로 1080×1350
슬라이드 수:
핵심 수치/소재:
CTA 목적지: (카톡채널 / 블로그링크 / 유튜브링크)
```

---

## 슬라이드 구조

### SLIDE 01 — HOOK (후킹)
**목적**: 스크롤 멈추게 하는 단 하나의 숫자 또는 질문

```
[레이아웃]
배경: 딥 네이비 (#1A2F5E)
중앙 상단: 작은 태그 텍스트 (시리즈명 or 카테고리)
중앙: 빅 넘버 또는 핵심 질문 (ExtraBold, 오프화이트)
하단: 1줄 부연 설명 (Regular, 미디엄 그레이)
우하단: 브랜드 슬로건 캡션

[텍스트]
태그:
빅 넘버/질문:
부연 설명:
```

---

### SLIDE 02 — PROBLEM (문제 제기)
**목적**: 타깃의 현실을 데이터로 보여줘 공감 유발

```
[레이아웃]
배경: 오프화이트 (#F7F8FA)
상단: 소제목 (SemiBold, 딥 네이비)
중앙: 데이터 시각화 (막대그래프 or 리스트)
- 레드(#C0392B)로 문제 구간 강조
하단: 1줄 결론 (Bold)

[텍스트]
소제목:
데이터 항목들:
결론 문장:
```

---

### SLIDE 03 — INSIGHT (핵심 인사이트)
**목적**: "이게 왜 문제인가"를 숫자로 증명

```
[레이아웃]
배경: 오프화이트
상단: 소제목
중앙: Before/After 비교표 또는 계산식
- 좌측(Before): 레드톤
- 우측(After): 그린·오렌지톤
하단: 손글씨 주석 오버레이 (딥 네이비)

[텍스트]
소제목:
Before 항목:
After 항목:
손글씨 주석:
```

---

### SLIDE 04 — EVIDENCE (근거·사례)
**목적**: 실제 사례로 신뢰 구축

```
[레이아웃]
배경: 딥 네이비
상단: "실제 사례" 배지 (오렌지 배경, 흰 텍스트)
중앙: 사례 수치 (크게)
하단: 익명 처리 캡션 "실제 고객 사례 (익명 처리)"

[텍스트]
사례 제목:
핵심 수치:
상황 설명 (2줄 이내):
캡션: 실제 고객 사례 (익명 처리)
```

---

### SLIDE 05 — METHOD (방법론)
**목적**: "나는 어떻게 다른가" 차별화 증명

```
[레이아웃]
배경: 오프화이트
상단: 소제목
중앙: 3단 리스트 or 비교 2컬럼
- 아이콘(라인 스타일) + 텍스트
하단: 강조 문구 (신뢰 블루 배경 박스)

[텍스트]
소제목:
항목 1:
항목 2:
항목 3:
강조 문구:
```

---

### SLIDE 06 (선택) — DEEPER DIVE (추가 설명)
**목적**: 더 알고 싶은 사람을 위한 심화 데이터

```
[레이아웃]
배경: 오프화이트
상단: 소제목
중앙: 꺾은선 그래프 or 표
하단: 출처 캡션

[텍스트]
소제목:
그래프 설명:
출처/기준:
```

---

### SLIDE 07 — CTA (행동 유도) — 필수 마지막 슬라이드
**목적**: 카톡 채널 또는 다음 행동으로 이동

```
[레이아웃]
배경: 딥 네이비 (#1A2F5E)
중앙 상단: 행동 유도 질문 (오프화이트, Bold)
중앙: CTA 버튼 블록 (오렌지 #E07C3A 배경, 흰 텍스트)
하단: 채널 링크 또는 아이디 정보
우하단: 브랜드 슬로건

[텍스트]
질문:
CTA 버튼 텍스트:
링크/아이디:
```

---

## 캡션 템플릿 (인스타그램 본문)

```
[후킹 첫 줄 — 숫자 or 질문]

[2~3줄 핵심 요약]

이 카드뉴스에서:
✔ [포인트 1]
✔ [포인트 2]
✔ [포인트 3]

증권 진단이 궁금하신 분 →
카톡 채널 [링크 또는 아이디] 로 증권 사진 한 장만 보내주세요.

이 카드, 배우자에게도 공유해보세요.

─────────────────
#보험증권진단 #보험료절감 #40대보험
```

(해시태그는 2025.12.18 Meta 공식 변경으로 5개 이하만 효과 있음 — 시리즈
고정 태그 2개 + 회차별 키워드 2~3개. "공유해보세요" 줄은 2026년 공식화된
공유(sends) 우선 순위 신호에 대응)

## 체크리스트 (발행 전)

- [ ] 슬라이드 1에 숫자 또는 질문이 있는가?
- [ ] Before/After 비교가 1곳 이상 있는가?
- [ ] 얼굴·인물 사진이 없는가?
- [ ] 마지막 슬라이드에 CTA가 있는가?
- [ ] 캡션에 핵심 해시태그 5개 이하로 포함되었는가? (9개 이상 X — 2025.12 Meta 제한)
- [ ] 캡션에 공유 유도 문구가 있는가? ("배우자에게 공유해보세요" 등)
- [ ] "실제 고객 사례 (익명 처리)" 표기가 있는가?
- [ ] 폰트 최소 22px 이상인가? (모바일 가독성)
- [ ] 슬라이드 간 색감·폰트가 일관되는가? (개별 생성 시 스타일 드리프트 확인)
