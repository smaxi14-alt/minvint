```
- 우측 헤더 배경: 안심 그린 (#27AE60), 흰 텍스트 "After"
- 행 줄무늬: 라이트 그레이 (#E8ECF0)

```

**소제목**: 증권 진단 전·후, 숫자로만 비교합니다

**비교표**:
```
                        Before          After
────────────────────────────────────────────────
월 보험료               78만원  →       56만원
보장 공백               3건     →       0건
중복 가입               2건     →       해소
실손 중복납부           있음    →       정리 완료
```

**오렌지 계산식 박스**:
```
78만원 − 56만원 = 월 22만원 절감
                  연 264만원 / 10년 2,640만원
```

**손글씨 주석**: ← 보장 구멍은 하나도 없습니다 ✓
