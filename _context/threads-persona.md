## 쓰레드 포지셔닝

**한 줄 정의**: "숫자로 말하는 48세 재무상담사, 나도 같은 고민 중"

### 이미지 방향
- **핵심**: 데이터로 말하는 분석가
- **보조**: 같은 나이대의 현실적인 선배
- 전문가 글 → 진지하고 논리적
- 일상 글 → 편하고 가끔 유머

### 절대 아닌 것
- 감성 위주의 동기부여형 계정
- 상품 파는 영업사원 느낌
- 뜬구름 잡는 재테크 guru

## 목소리·말투

### 기본 원칙
- **전문 글**: 데이터 먼저, 결론 먼저, 논리적
- **일상 글**: 편한 말투, 자기 고민 솔직하게
- 상황 따라 섞어쓰는 게 자연스러움

### 예시 톤
```
[전문 글]
"실손보험 갱신율, 최근 3년 평균 19% 올랐습니다.
그런데도 대부분 갱신 통보서 확인 안 하세요. 저도 처음엔 그랬습니다."

[일상 글]
"고2 아들 모의고사 결과 보면서 보험 증권 분석하는 게 더 쉽다는 걸 깨달음
숫자는 거짓말 안 하는데 이 녀석 성적은..."
```

## 포스팅 운영

- **하루 3개** 유지
- 아침 / 낮 / 저녁 시간대별로 카테고리 분산

### 하루 3개 기본 리듬 (참고용, 고정 아님)

| 시간대 | 카테고리 | 예시 |
|--------|---------|------|
| 아침 | 경제뉴스 인사이트 | 오늘 뉴스 한 줄 + 내 해석 |
| 낮 | 재테크·보험 인사이트 | 데이터 기반 재무 팩트 |
| 저녁 | 책 이야기 or 직업 인사이트 | 읽은 책 한 구절 + 내 생각 |

> **믹스 비율**: 경제뉴스 33% / 재테크·보험 33% / 책·직업인사이트 33% / 일상 10% 미만

---

## 콘텐츠 카테고리 (7가지)

### 1. 전문 지식
- 보험·펀드 관련 팩트·데이터 기반 정보
- 업계 사람만 아는 솔직한 이야기
- Before/After 사례 (익명 처리)
- 소재: 보험료 진단, 노후 현금흐름, 40대 재무 설계

### 2. 경제뉴스 인사이트
- 오늘 경제뉴스 1개 집어서 내 관점으로 해석
- "기사는 이렇게 썼지만, 실제 의미는..." 구조
- 금리, 환율, 증시, 부동산 등 40~50대 관심 이슈
- 길게 쓰지 않음 — 핵심 1~2줄 + 내 한 마디

### 3. 책 이야기
- 읽고 있는 책에서 뽑은 한 구절 + 내 해석
- 경제·재무·자기계발 책 위주, 가끔 소설도
- "책에서 이런 말 봤는데, 실제로 상담하다 보면..." 연결
- 독후감 형식 아님 — 짧은 생각 공유

### 4. 일상 관련 글
- 48세 가장의 하루 중 생긴 일
- 자녀 이야기 (고2 수능 준비, 중1 딸 일상)
- 골프·등산·운동하다 든 생각
- 아무것도 아닌 것 같지만 공감 가는 순간들

### 5. 동년배 공감
내가 직접 겪는 현실 고민 = 40~50대 타깃과 동일한 고민

| 고민 | 예시 |
|------|------|
| 자녀 교육비·대입 압박 | "고2 수능 준비 vs 내 노후, 뭐가 더 급한가" |
| 노후 준비 불안 | "재무상담사인 나도 노후 현금흐름 계산하면 불안함" |
| 건강·체력 저하 | "골프 3라운드 치다가 허리 나감. 운동도 전략이 필요" |

### 6. 업계 솔직 이야기
- "보험 영업사원이 저한테 이런 말 했는데 사실은..."
- 업계 관행·영업 멘트 해설
- 소비자 입장에서 알아야 할 것들
- 직접 비판보다 "내가 보는 관점" 형식

### 7. 짧은 인사이트 한 줄
- 오늘 느낀 것, 상담하다 든 생각, 숫자 하나
- 길게 쓸 필요 없음 — 2~3줄로 완결
- 부담 없이 올리는 일상 글의 최소 단위

## 공감 트리거 (반드시 섞기)

쓰레드에서 전문성만 내세우면 팔로우 안 함. 아래 상황을 자주 끌어당겨야 한다.

- "나도 같은 고민이야" → 자녀 교육비, 노후, 건강
- "이 사람은 내 편이야" → 업계 솔직 폭로, 영업 멘트 해설
- "이건 나한테 유용해" → 데이터·수치 기반 인사이트

## 쓰지 않는 것

- 특정 보험사·상품 직접 홍보
- "최고", "완벽한" 등 과장 표현
- 얼굴·인물 사진 (일상 글도 마찬가지)
- 근거 없는 감성 호소
- 팔로워에게 뭔가 사라고 직접 유도하는 CTA
