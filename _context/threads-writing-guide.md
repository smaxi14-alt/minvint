# 쓰레드 글쓰기 가이드 v1.0

> 모든 글의 뼈대: 후크 1줄 → 본문 2~5줄 → 마무리 질문 1줄

---

## 기본 규칙

| 항목 | 기준 |
|------|------|
| 분량 | 200~350자 (이상적) / 500자 초과 금지 |
| 줄바꿈 | 2~3문장마다 1줄 필수 |
| 숫자 | 항상 구체적으로 (월 300만원 ❌ / 월 317만원 ✅) |
| 구조 | 결론 먼저, 마지막에 질문 |
| 이모지 | 사용 안 함 |
| 과장 표현 | 절대 금지 (최고, 완벽, 꼭, 반드시) |

---

## 후크 공식 5종

### 1. 숫자형
```
[충격적인 숫자] + [뜻밖의 사실]
```
예: "와이프 카드값 12개월 합산해보니 연 840만원이었다."

---

### 2. 반전형
```
[예상 가능한 전제] + [뒤집기]
```
예: "월 1,200 버는 친구가 우리 중 가장 가난하다."

---

### 3. 고백형
```
[숨기고 싶은 것]을 솔직히 말한다.
```
예: "와이프 몰래 매달 1만원씩 따로 보내는 통장이 있다."

---

### 4. 관찰형
```
[기간] [관찰 대상]에서 발견한 공통점이 있다.
```
예: "13년간 부자 고객들을 보다가 한 가지 패턴을 발견했다."

---

### 5. 금기형
```
[대상]이 절대 [말 안 하는 / 하면 안 되는] [것].
```
예: "보험설계사가 고객한테 절대 말 안 하는 진실이 있다."

---

## 마무리 질문 공식

**원칙**: 특정 그룹을 호명. 답을 강요하지 않음.

| 나쁜 예 | 좋은 예 |
|---------|---------|
| "다들 어떻게 생각함?" | "내 또래만 공감할 듯" |
| "댓글로 알려줘요" | "40대 가장들 비슷한 경험 있음?" |
| "공감하면 좋아요!" | "이거 나만 그래?" |
| "여러분 생각은요?" | "솔직히 얼마인지 아는 사람?" |

## 템플릿 6종

### 템플릿 A. 충격 통계 + 해석

```
[충격적인 통계 한 줄]
[의미 풀이 2~3줄]

13년 보면서 느낀 건데 [관찰 해석 1줄].

[마무리 질문]
```

예시:
```
40대 가구 평균 부채가 1억 1천이라는 통계 봤다.
더 충격인 건 그중 절반이 신용·카드 부채라는 점.

13년 보면서 느낀 건데, 부채 1억 있는 사람들 대부분 본인은 5천이라고 함. 정확히 두 배씩 과소평가.

본인 부채 정확히 아는 사람?
```

---

### 템플릿 B. 두 숫자 비교

```
[A 숫자] vs [B 숫자].
차이가 [X]다.

근데 이 차이의 진짜 의미는 [해석].

[마무리 질문]
```

예시:
```
40대 가구 월평균 소득 580만원.
40대 가구 월평균 지출 470만원.
차이 110만원.

근데 이게 평균이고, 실제로는 절반이 매달 적자.
결국 평균은 잘 버는 사람들이 만든 환상.

본인 월 흑자 진짜 얼마임?
```

---

### 템플릿 C. 시간축 비교

```
5년 전: [숫자 A]
지금: [숫자 B]

[X% 변화]처럼 보이지만 [반전 사실].

[의미 한 줄]

[마무리 질문]
```

---

### 템플릿 D. 세대 격차

```
[A세대] [데이터].
[B세대] [데이터].

이게 단순 숫자 차이가 아니라 [진짜 의미].

[40대에게 주는 시사점]

[마무리 질문]
```

---

### 템플릿 E. 체크리스트 (Phase 3 전환에 가장 강력)

```
[상황 프레임 한 줄].

– [항목 1]
– [항목 2]
– [항목 3]
– [항목 4]
– [항목 5]

[X]개 이상이면 [의미].

[마무리 질문]
```

핵심: Phase 3에서 "보험 증권 몇 장인지 모름" 같은 항목 끼워 CTA 자연 연결.

---

### 템플릿 F. 어그로·공감 (일상 소재)

```
[고백/반전/충격 후크 한 줄].

[상황 설명 2~3줄 — 구체적인 숫자·인물·상황 필수]

[감정이나 깨달음 한 줄].

[마무리 질문]
```

## 톤 변환표

| 나쁜 표현 | 좋은 표현 |
|----------|----------|
| "정말 중요한 문제입니다" | "솔직히 이게 제일 무섭더라" |
| "전문가로서 말씀드리면" | "13년 보면서 느낀 건데" |
| "꼭 확인해보세요" | "한번 세어봐 진심으로" |
| "보험이 중요합니다" | "증권 몇 장인지 모르는 사람 생각보다 많음" |
| "고객님의 재정 상황을" | "내가 만난 47살 가장 중에" |

---

## 절대 쓰지 않는 표현

- 최고, 완벽, 꼭, 반드시, 필수
- 감사합니다 / 공유 부탁드립니다 / 구독해주세요
- "오늘은 X에 대해 알아보겠습니다"
- 보험사 이름 직접 언급
- "월 수백만원 절약 가능" 류 수익 과장

---

## 발행 전 셀프 체크리스트

- [ ] 첫 줄에서 멈추게 되는가?
- [ ] 숫자·디테일이 구체적인가? (월 300 ❌ / 월 317만원 ✅)
- [ ] 과장 표현이 없는가?
- [ ] 마지막 줄이 특정 그룹 호명 질문인가?
- [ ] 200~500자 범위인가?
- [ ] 줄바꿈이 2~3줄마다 있는가?
- [ ] 현재 Phase에 맞는 콘텐츠 타입인가?
- [ ] 최근 3일 내 비슷한 주제를 쓰지 않았는가?

## 변주 전략

**떡상한 글 재활용**: 반응 좋은 글은 2주 후에 후크와 디테일만 바꿔 재발행.  
예: "와이프 카드값" → "딸 학원비" / "동창회 쇼크" → "부장 진급 소식"

**A/B 테스트**: 같은 주제를 다른 후크로 2주 간격으로 각 1개씩.  
반응 데이터로 내 계정에 맞는 후크 유형 파악.

**절대 금지**: 블로그·유튜브 2차 인용. 원본 보고서 원문 확인 후만 사용.
