# 쓰레드 글쓰기 가이드 v2.0

> 모든 글의 뼈대: 후크 1줄 → 본문 2~5줄 → 마무리 질문 1줄

---

## 콘텐츠 믹스 (기본 운영 기준)

| 유형 | 비율 | 슬롯 | 소재 출처 |
|------|------|------|---------|
| YouTube 경제뉴스 해석 | 35% | 점심 | @김영익, @howtoberich_official 채널 분석 |
| YouTube 직업 인사이트 | 35% | 저녁 | @김영익, @howtoberich_official 채널 분석 |
| 어그로 / 일상 | 20% | 아침 | content_seeds.json agro_empathy |
| 재테크 데이터 | 10% | Phase 1 저녁 | content_seeds.json finance + agro_finance 혼합 |

> **Phase 1 저녁**: agro_finance(공감 70% + 재테크 30% 혼합)로 운영해 재테크 10%를 자연스럽게 커버  
> **Phase 2~3 저녁**: job_insight(YouTube 직업 인사이트)로 전환, YouTube 소재 70% 완성

## 후크 공식 5종

### 1. 숫자형
```
[YouTube 분석 수치] + [내 해석 또는 반전]
```
예: "삼성전자 PER 7배. S&P500은 20배. 같은 반도체인데 시장은 왜 다르게 보냐."

---

### 2. 반전형
```
[뉴스·시장이 말하는 것] + [실제 내 현실 또는 진짜 의미]
```
예: "코스피 작년 4월부터 250% 올랐다는 뉴스 봤다. 근데 내 포트폴리오는 -8%."

---

### 3. 고백형
```
[재무상담사로서 숨기고 싶은 것]을 솔직히 말한다.
```
예: "고객이 반도체주 고점 언제냐고 물어볼 때 기준 없어서 멍한 적 있다."

---

### 4. 관찰형
```
[기간] [관찰]에서 발견한 시장 또는 고객 패턴
```
예: "13년 경험상 인기주는 항상 과하게 오르고, 외면받은 종목은 과하게 떨어진다."

---

### 5. 금기형
```
[전문가·언론]이 잘 말 안 하는 것
```
예: "사이클 산업 애널리스트 예측이 자주 틀린다는 걸 전문가들은 잘 말 안 한다."

## 마무리 질문 공식

**원칙**: 특정 그룹을 호명. 답을 강요하지 않음.

| 나쁜 예 | 좋은 예 |
|---------|---------|
| "다들 어떻게 생각함?" | "내 또래만 공감할 듯" |
| "댓글로 알려줘요" | "40대 가장들 비슷한 경험 있음?" |
| "공감하면 좋아요!" | "이거 나만 그래?" |
| "여러분 생각은요?" | "솔직히 얼마인지 아는 사람?" |

## 템플릿 7종

### 템플릿 A. 충격 통계 + 해석

```
[충격적인 통계 한 줄]
[의미 풀이 2~3줄]

13년 보면서 느낀 건데 [관찰 해석 1줄].

[마무리 질문]
```

예시:
```
40대 가구 평균 부채가 1억 1천이라는 통계 봤다.
더 충격인 건 그중 절반이 신용·카드 부채라는 점.

13년 보면서 느낀 건데, 부채 1억 있는 사람들 대부분 본인은 5천이라고 함. 정확히 두 배씩 과소평가.

본인 부채 정확히 아는 사람?
```

---

### 템플릿 B. 두 숫자 비교

```
[A 숫자] vs [B 숫자].
차이가 [X]다.

근데 이 차이의 진짜 의미는 [해석].

[마무리 질문]
```

예시:
```
40대 가구 월평균 소득 580만원.
40대 가구 월평균 지출 470만원.
차이 110만원.

근데 이게 평균이고, 실제로는 절반이 매달 적자.
결국 평균은 잘 버는 사람들이 만든 환상.

본인 월 흑자 진짜 얼마임?
```

---

### 템플릿 C. 시간축 비교

```
5년 전: [숫자 A]
지금: [숫자 B]

[X% 변화]처럼 보이지만 [반전 사실].

[의미 한 줄]

[마무리 질문]
```

---

### 템플릿 D. 세대 격차

```
[A세대] [데이터].
[B세대] [데이터].

이게 단순 숫자 차이가 아니라 [진짜 의미].

[40대에게 주는 시사점]

[마무리 질문]
```

---

### 템플릿 E. 체크리스트 (Phase 3 전환에 가장 강력)

```
[상황 프레임 한 줄].

– [항목 1]
– [항목 2]
– [항목 3]
– [항목 4]
– [항목 5]

[X]개 이상이면 [의미].

[마무리 질문]
```

핵심: Phase 3에서 "보험 증권 몇 장인지 모름" 같은 항목 끼워 CTA 자연 연결.

---

### 템플릿 F. 어그로·공감 (일상 소재)

```
[고백/반전/충격 후크 한 줄].

[상황 설명 2~3줄 — 구체적인 숫자·인물·상황 필수]

[감정이나 깨달음 한 줄].

[마무리 질문]
```

---

### 템플릿 G. 후기·소개 유도형 (Phase 3 진단소 후속 전용)

```
[진단 후 실제 반응 또는 근황 한 줄].

[상황 설명 1~2줄 — 무엇이 달라졌는지, 담담하게].

[소회 한 줄].

[마무리 — 소개를 유도하되 요청하지 않는다]
```

예시:
```
지난달 진단해드린 분이 어머니 증권도 한번 봐달라고 하셨다.

본인 것 정리하고 나니 옆에 있는 사람 것도 보이더라고.

이런 식으로 이어지는 게 이 일의 진짜 보람이다.

주변에 증권 서랍에 넣어두기만 한 사람, 꽤 많을 거다.
```

**핵심 규칙**: "공유해주세요", "소개해주세요" 같은 직접 요청 문장 금지(금기
사항 위반). 사례를 담담히 보여주는 것으로 끝낸다 — 소개는 독자가 스스로
떠올리게 만드는 것이지 요청하는 게 아니다.

## 톤 변환표

| 나쁜 표현 | 좋은 표현 |
|----------|----------|
| "정말 중요한 문제입니다" | "솔직히 이게 제일 무섭더라" |
| "전문가로서 말씀드리면" | "13년 보면서 느낀 건데" |
| "꼭 확인해보세요" | "한번 세어봐 진심으로" |
| "보험이 중요합니다" | "증권 몇 장인지 모르는 사람 생각보다 많음" |
| "고객님의 재정 상황을" | "내가 만난 47살 가장 중에" |

---

## 절대 쓰지 않는 표현

- 최고, 완벽, 꼭, 반드시, 필수
- 감사합니다 / 공유 부탁드립니다 / 구독해주세요
- "오늘은 X에 대해 알아보겠습니다"
- 보험사 이름 직접 언급
- "월 수백만원 절약 가능" 류 수익 과장

## 발행 전 셀프 체크리스트

- [ ] 첫 줄에서 멈추게 되는가?
- [ ] 숫자·디테일이 구체적인가? (월 300 ❌ / 월 317만원 ✅)
- [ ] 과장 표현이 없는가?
- [ ] 마지막 줄이 특정 그룹 호명 질문인가?
- [ ] 200~500자 범위인가?
- [ ] 줄바꿈이 2~3줄마다 있는가?
- [ ] 현재 Phase에 맞는 콘텐츠 타입인가?
- [ ] 최근 3일 내 비슷한 주제를 쓰지 않았는가?

## 변주 전략

**떡상한 글 재활용**: 반응 좋은 글은 2주 후에 후크와 디테일만 바꿔 재발행.  
예: "와이프 카드값" → "딸 학원비" / "동창회 쇼크" → "부장 진급 소식"

**A/B 테스트**: 같은 주제를 다른 후크로 2주 간격으로 각 1개씩.  
반응 데이터로 내 계정에 맞는 후크 유형 파악.
