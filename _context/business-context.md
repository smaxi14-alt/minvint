## 시장 맥락

### 왜 지금 이 포지셔닝인가

**한국 보험 시장의 구조적 현실**
- 가구당 평균 보험 가입 건수: 4~5건
- "이게 맞나?" 의심하는 기가입자 > 신규 가입 대기자
- 대부분의 설계사·마케팅은 **신규 가입** 중심 → 기가입자 시장은 상대적 블루오션

**GA 소속의 구조적 무기**
- 전속 설계사: 자사 상품만 취급, "최저가 비교표" 불가능
- GA 설계사: 다수 보험사 상품 비교 가능 → **비교** 키워드를 정당하게 점유 가능
- 베테랑 + GA + 비교표 = 시장에서 가장 강력한 신뢰 트리거

**동년배 설계사의 희소성**
- 40대 중산층 타깃에게 20~30대 인플루언서 설계사 = "내 사정 모르는 애"
- 베테랑 설계사 = "내 또래 형, 내 동생" → 살 수 없는 공감 자산

## 타깃 시장 세분화

### 4분면 매트릭스

| | 재무 자신감 낮음 | 재무 자신감 높음 |
|---|---|---|
| **보험 多 (4건+)** | 🟦 불안형 과보험자 ★ 1순위 | 🟥 합리형 점검자 ★ 2순위 |
| **보험 少 (1~3건)** | 🟨 방치형 미흡자 (후순위) | 🟩 설계형 입문자 (후순위) |

### 1순위: 🟦 불안형 과보험자 (김부장 페르소나)
- **Pain Point**: "줄이고 싶지만 손해 볼까봐 못 건드린다" → 결정 마비 상태
- **시장 규모**: 한국 가구의 절반 이상 해당 (가장 큰 시장)
- **경쟁 강도**: 낮음 (대부분 신규 가입 공략에 집중)
- **전환 CTA**: "카톡으로 증권 사진 → 무료 1차 진단"

### 2순위: 🟥 합리형 점검자 (박과장 페르소나)
- **Pain Point**: "내가 짠 설계가 지금도 맞는지 검증받고 싶다"
- **특성**: 정보 탐색형, 블로그·유튜브 정독, 영업 멘트 즉각 거부
- **LTV**: 높음 — 한 번 신뢰 형성 시 가족·지인 소개로 확장
- **전환 CTA**: "30분 줌 미팅으로 포트폴리오 점검"

### 후순위 타깃 (1년차 제외 권장)
- 🟨 방치형 미흡자: 보험 필요성부터 설득해야 해 설득 비용 과다
- 🟩 설계형 입문자: 수 적고 은행 PB와 경쟁 구도 형성

## 비즈니스 모델

### 수익 구조 (3단 깔때기)

```
[유입] 보험료 다이어트 콘텐츠
       → 블로그 SEO, 인스타 바이럴
       ↓
[전환] 보험 증권 무료 1차 진단
       → 카톡 채널 CTA
       ↓
[업셀] 은퇴 현금흐름 설계 컨설팅
       → 연금·저축성 보험 계약
```

### 고객 생애가치(LTV) 확장 전략
1. **진입**: 기존 보험 정리·절감 (단기 신뢰 획득)
2. **확장**: 연금·저축성 설계 (중기 계약)
3. **심화**: 가족 단위 포트폴리오 관리 (장기 관계)
4. **소개**: 지인 소개 네트워크 (CAC 0원 신규 유입)

### 가격 포지셔닝 함정 방지
- "비교표 = 가격 경쟁"으로 끌려갈 위험 존재
- **대응**: 비교를 1막(훅)으로만 사용, 2막에서 반드시 "은퇴 후 현금흐름 설계"로 전환
- 차별화: "더 싼 상품" 대신 "당신에게 맞는 설계" 프레임 유지

## 채널 전략

### 역할 분담

| 채널 | 역할 | 주요 타깃 | 핵심 KPI |
|------|------|-----------|---------|
| 블로그·네이버 | 유입 본진 (SEO) | 김부장 (검색) | 월 검색 유입, 카톡 채널 추가 수 |
| 인스타그램 | 브랜드 신뢰 자산화 | 김부장 (첫인상) | 저장 수 (좋아요보다 저장 우선) |
| 유튜브 | 권위·깊이 증명 | 박과장 (검증) | 시청 지속률, 댓글 질문 수 |
| 카카오톡 채널 | 전환 깔때기 | 전 채널 통합 | 채널 친구 수, 1:1 상담 전환률 |

### 트래픽 흐름
```
블로그 검색 유입 ──┐
인스타 발견     ──┤──→ 카카오톡 채널 → 1:1 상담 → 계약
유튜브 시청     ──┘
```

### 콘텐츠 제작 우선순위 (월 5개+ 기준)
1. **블로그 장문 분석글** 2편 (SEO 핵심)
2. **인스타 카드뉴스** 2편 (브랜드 노출)
3. **유튜브 분석 영상** 1편 (권위 증명)
4. **카톡 채널 피드** 수시 (전환 유지)

## 경쟁 포지셔닝

### 가상 경쟁자 프레임 (고객 머릿속에 심을 비교 기준)
> "보험다모아는 신상품만 비교합니다. 저는 당신이 이미 가지고 있는 증권을 비교합니다."

| 경쟁 유형 | 그들의 한계 | 우리의 포지션 |
|-----------|-----------|--------------|
| 비교 플랫폼 (보험다모아 등) | 신상품 중심, 개인 상황 미반영 | 기존 증권 + 개인 맞춤 분석 |
| AI 비교 서비스 | 평균 데이터 기반 | 개별 건강·소득·가족 상황 반영 |
| 전속 설계사 | 단일 보험사 상품만 | 전 사 비교 후 최적 설계 |
| 인플루언서 설계사 | 젊고 트렌디하나 공감 부족 | 동년배의 10년 경험 |

## 실행 로드맵

### 1단계 (1~2개월): 기초 세팅
- [ ] 블로그 시그니처 콘텐츠 10편 완성 (비교표·계산기 형태)
- [ ] 인스타 프로필 통일 (사진, 바이오, 링크트리)
- [ ] 카카오톡 채널 개설 + 자동 응답 시나리오 설정
- [ ] "증권 진단 1차 신청" CTA 프로세스 구축

### 2단계 (3~4개월): 채널 교차 연결
- [ ] 유튜브 시작 + 블로그·카카오채널 연동
- [ ] "데이터로 보는 보험" 시리즈명 고정 브랜딩
- [ ] 실제 상담 사례 익명 후기 콘텐츠화 시작

### 3단계 (5~6개월): 전문가 인증
- [ ] 네이버 엑스퍼트 또는 카카오 전문가 채널 등록 검토
- [ ] 월 1회 "보험 점검 이벤트" 정례화
- [ ] 소개 고객 비율 측정 시작 (LTV 관리)

## 핵심 콘텐츠 시리즈 (즉시 활용)

| 시리즈명 | 타깃 | 채널 | 예시 제목 |
|---------|------|------|----------|
| 증권 진단 실사례 | 김부장 | 블로그+유튜브 | "실제 47세 고객 증권, 월 22만원 줄인 과정" |
| 보험료 다이어트 | 김부장 | 인스타+블로그 | "암보험 진단비 5천 vs 3천, 차이 나는 순간" |
| 은퇴 현금흐름 | 박과장 | 유튜브+블로그 | "60세부터 월 300만원, 실제 설계 가능한가" |
| GA 설계사의 솔직한 말 | 전체 | 전 채널 | "GA 설계사가 말하는 보험사별 진짜 장단점" |
| 40대 보험 공백 시리즈 | 김부장 | 인스타+블로그 | "40대 가장이 놓치는 보험 공백 TOP 3" |
| 셀프 체크리스트 (신규) | 김부장 | 인스타(저장 전용) | "내 보험 다이어트 가능 여부 셀프 체크 10문항" |

**"셀프 체크리스트" 신설 배경**: 인스타 KPI는 "좋아요보다 저장 수 우선"인데
(아래 채널 전략 표), 지금까지의 5개 시리즈는 전부 서사·정보형이라 저장을
목적으로 설계된 콘텐츠가 없었다. 이 시리즈는 카드뉴스 마지막 장이 항상
"저장해두고 나중에 체크하세요" 톤으로 끝나는 게 특징 — 다른 시리즈처럼
CTA로 끝나지 않아도 된다(저장 자체가 1차 목표, 카톡 전환은 2차).

> **참고 — 콘텐츠 폴더에서 추가로 확인된 카테고리(2026-07-21 기준)**: `건강검진`,
> `숨은보험금`, `threads-저축률`, `쓰레드-카드뉴스` 등이 `콘텐츠/` 폴더에 이미
> 존재하지만 이 표에는 없었다. 잠정 매핑 — `건강검진`은 40대 보험 공백
> 시리즈의 하위 소재, `숨은보험금`은 증권 진단 실사례의 하위 소재로 본다.
> `threads-저축률`·`쓰레드-카드뉴스`는 전략 시리즈가 아니라 쓰레드용 카드뉴스
> 산출물 아카이브 폴더로 판단된다. 이 매핑은 추정이며, 실제 기획 의도와
> 다르면 정정이 필요하다.
