# 쓰레드(Threads) 운영 전략서 v1.0

> 목표: 사람으로 잡히기 → 신뢰 쌓기 → 전환  
> 원칙: 보험 먼저 꺼내면 진다

---

## 계정 포지셔닝

| 항목 | 내용 |
|------|------|
| 계정 한 줄 | "13년차 보험설계사 / 40대 가장 / 솔직한 얘기만" |
| 얼굴 노출 | 없음 (Threads는 텍스트 플랫폼, 불필요) |
| 브랜드명 노출 | "증권진단소" — Phase 3 이후에만 |
| 톤 | 의사 진찰실 ❌ → 형이 옆에서 술 한잔 하며 얘기해주는 스타일 ✅ |

## 3단계 로드맵

### Phase 1 — 씨앗기 (운영 1~90일 / 목표 팔로워 3,000)

| 콘텐츠 유형 | 비율 | 슬롯 |
|------------|------|------|
| YouTube 경제뉴스 해석 | 35% | 점심 |
| 어그로·일상 | 35% | 아침 + 저녁 일부 |
| 재테크·일상 혼합 (agro_finance) | 20% | 저녁 |
| 보험 (절대 영업 없음) | 10% | — |

- **목표**: "이 계정 재밌네" + "경제 얘기 잘하네" 인식 동시 형성
- **금기**: 보험 영업 일절, 직업 언급 최소화
- **핵심 KPI**: 팔로워 증가율, 리포스트 수

---

### Phase 2 — 전환기 (91~180일 / 목표 팔로워 10,000)

| 콘텐츠 유형 | 비율 | 슬롯 |
|------------|------|------|
| YouTube 경제뉴스 해석 | 35% | 점심 |
| YouTube 직업 인사이트 | 35% | 저녁 |
| 어그로·일상 | 20% | 아침 |
| 재테크 데이터 | 10% | 저녁 일부 교체 |

- **목표**: "이 사람 시장도 읽고 13년 경험도 있네" 신뢰 구축
- **전략**: "13년 일하면서 본 건데..." 정체성 자연스럽게 노출
- **핵심 KPI**: 저장률, 팔로워 증가율

---

### Phase 3 — 수익화기 (181일~)

| 콘텐츠 유형 | 비율 | 슬롯 |
|------------|------|------|
| YouTube 경제뉴스 해석 | 30% | 점심 |
| YouTube 직업 인사이트 | 25% | 저녁 일부 |
| 어그로·일상 | 20% | 아침 |
| 진단소 — 신규 사례 | 15% | 저녁 |
| 진단소 — 후속(후기·소개 유도) | 5% | 저녁 |
| CTA (카톡 채널, 진단 글에만) | 5% | 저녁 진단 글 끝 |

- **목표**: "이 사람한테 증권 보여줘도 될 것 같다"
- **전략**: 실제 익명 사례 + 체크리스트 + 카톡 CTA
- **핵심 KPI**: 카톡 구독자 증가, 진단 신청 건수, 소개 유입(추정치 — 아래 참고)

> **왜 "진단소"를 둘로 쪼갰나**: 기존 20%가 전부 "신규 진단 사례"에만 쓰이면
> `business-context.md`의 LTV 확장 3단계("진입→확장→심화→**소개**") 중 소개
> 단계를 겨냥한 콘텐츠가 구조적으로 0%가 된다. 후속 5%는 이미 진단받은
> 고객의 담담한 후기·근황을 다뤄 "정리하고 나니 옆 사람 것도 보인다"는
> 자연스러운 소개 유도를 만든다 — 템플릿은 `threads-writing-guide.md`
> 템플릿 G 참조. 팔로워에게 직접 "공유해주세요"라고 요청하지 않는다
> (금기 사항 위반) — 사례를 담담히 보여줄 뿐, 행동을 강요하지 않는다.

| 저녁 | 21:00 | 일상·직업 인사이트 | 댓글 활성화 |

| 슬롯 | Phase 1 | Phase 2 | Phase 3 |

## 콘텐츠 필러 4개

### A. 어그로·공감 (Phase 1 주력)
**소재**: 와이프·자식·직장·동창 비교·나이듦·돈 격차  
**목표**: 팔로워 유입, 리포스트

### B. 재테크·돈 이야기 (Phase 2~3 핵심)
**공식**: 데이터 1개 + 13년차 해석 1줄  
**목표**: 저장률, 전문성 신뢰

### C. 직업 인사이트 (Phase 2 후반~)
**방향**: 13년간 관찰한 패턴, 영업 없는 관찰자 포지션  
**목표**: 차별화, "이 사람 진짜네" 인식

### D. 진단소 (Phase 3)
**형식**: 실제 익명 사례 + 체크리스트 + 카톡 CTA  
**목표**: 카톡 전환, 진단 신청

**서브타입 2개** (Phase 3 비율표 참조):
- **신규 사례** (15%): 새로운 익명 진단 사례 + 체크리스트, 신규 카톡 전환 타깃
- **후속 — 후기·소개 유도** (5%): 이미 진단받은 고객의 담담한 근황·후기.
  "정리하고 나니 옆 사람 것도 보이더라" 식으로 소개를 자연스럽게 유도한다
  (직접 "공유해주세요" 요청 금지 — 템플릿 G 참조)

## 댓글 활동 전략

**원칙**: 초반 성장에 본인 글만큼, 어쩌면 더 중요.

- 트렌딩 글 3~5개에 인사이트 댓글 달기 (매일)
- 큰 계정 댓글창에서 좋아요 받는 댓글 1개 = 팔로워 100명 효과
- 댓글 기준: "맞아요" ❌ → "13년 보면서 같은 상황 봤는데 결말이 달랐음" ✅

## KPI 목표치

| 지표 | Phase 1 목표 | Phase 2 목표 | Phase 3 목표 |
|------|-------------|-------------|-------------|
| 팔로워 | +100/주 | +300/주 | +500/주 |
| 저장률 (글별) | 2% | 4% | 6% |
| 리포스트율 | 1% | 2% | 3% |
| 카톡 구독자 | - | +10/월 | +50/월 |
| 진단 신청 | 0 | 0~5건/월 | 20건+/월 |
| 소개 유입 (추정) | - | - | 월 2건+ (자기보고 기준*) |

*소개 유입은 쓰레드 자체로는 출처 추적이 불가능하다 — 카톡 상담 시 "어떻게
알게 되셨어요?" 질문에 "지인 소개"라고 답한 건수를 수동 집계하는 방식이
현재로선 유일한 근사치다. `blog-daily-automation-strategy.md`의
`outcome` 필드처럼 자동 태깅할 방법이 없으므로, 정확한 지표라기보다
후속 콘텐츠(위 D 서브타입)가 실제로 작동하는지 보는 방향 지표로만 쓴다.

## 금기 사항

- 정치, 종교, 젠더, 특정 보험사 비방
- 다른 설계사 디스
- 광고성 글 (Phase 1~2)
- AI 티 나는 문어체, 줄바꿈 없는 덩어리 글
- "최고", "완벽", "꼭 하세요" 류 과장 표현
- 데이터 없는 감성·공감 위주 글

## 주간 성과 분석 루틴 (매주 일요일)

1. 좋아요 TOP 3 글 → 후크 공통점 파악
2. 저장 TOP 3 글 → 주제·템플릿 분석
3. 댓글 많은 글 → 마무리 질문 패턴 분석
4. **(신규)** 블로그 최근 7일 발행 글의 `series`·`tier`별 `outcome` 집계
   (`blog_tracker.get_outcome_breakdown()`) 확인 → 진단 신청으로 이어진
   시리즈·티어가 있으면 다음 주 콘텐츠 믹스 비중 상향 검토
   (`blog-daily-automation-strategy.md` 10.1 참조)
5. 다음 주 콘텐츠 조정에 반영 (생성 프롬프트 업데이트)
