# 디자인 스타일 가이드

## 디자인 철학

> "얼굴 대신 데이터로 말한다. 의사가 차트로 신뢰를 주듯, 그래프와 표가 곧 얼굴이다."

얼굴 비노출 + 데이터 중심 = **분석가형 비주얼 아이덴티티**
모든 디자인 결정은 "신뢰감"과 "정보 명확성"을 최우선 기준으로 판단한다.

## 컬러 팔레트

### 메인 컬러
| 역할 | 색상명 | HEX | 사용처 |
|------|--------|-----|--------|
| Primary | 딥 네이비 | `#1A2F5E` | 제목, 강조 텍스트, 헤더 배경 |
| Secondary | 신뢰 블루 | `#2B6CB0` | 그래프 주요 데이터, 버튼, 링크 |
| Accent | 포인트 오렌지 | `#E07C3A` | Before/After 비교의 'After', CTA 버튼 |

### 서브 컬러
| 역할 | 색상명 | HEX | 사용처 |
|------|--------|-----|--------|
| Background | 오프화이트 | `#F7F8FA` | 카드 배경, 슬라이드 배경 |
| Surface | 라이트 그레이 | `#E8ECF0` | 구분선, 테이블 줄무늬 |
| Negative | 알림 레드 | `#C0392B` | Before(손해 구간), 경고 수치 |
| Positive | 안심 그린 | `#27AE60` | After(절감 구간), 이득 수치 |
| Text | 차콜 | `#2C3E50` | 본문 텍스트 |
| Text Light | 미디엄 그레이 | `#7F8C8D` | 부제, 캡션 |

### 컬러 사용 원칙
- **Before(현재 상태)** = 레드 계열 → 문제·손해 시각화
- **After(개선 후)** = 그린·오렌지 계열 → 해결·절감 시각화
- 배경은 항상 밝게, 데이터 요소만 진하게 — 정보가 주인공

## 타이포그래피

### 한국어 폰트
| 용도 | 폰트 | 굵기 | 크기 가이드 |
|------|------|------|------------|
| 제목 (H1) | Noto Sans KR / Pretendard | Bold (700) | 28~36pt |
| 소제목 (H2) | Noto Sans KR / Pretendard | SemiBold (600) | 20~24pt |
| 본문 | Noto Sans KR / Pretendard | Regular (400) | 14~16pt |
| 캡션·출처 | Noto Sans KR | Light (300) | 10~12pt |
| 강조 숫자 | Pretendard | ExtraBold (800) | 36~48pt |

### 숫자·데이터 전용 폰트
| 용도 | 폰트 | 특성 |
|------|------|------|
| 수치 강조 | Roboto / Inter | 고정폭 숫자, 정렬감 |
| 그래프 라벨 | Roboto Condensed | 좁은 공간에서 가독성 |

### 타이포 원칙
- 숫자는 크게, 단위는 작게 (예: **22**만원)
- 강조어는 색상으로, 볼드는 절제해서 사용
- 줄간격 1.6 이상 — 정보 밀도가 높아도 숨통이 있어야 함

## 비주얼 요소

### 시그니처 콘텐츠 형식

#### 1. Before/After 비교표
```
┌─────────────────────────────────────┐
│  현재 설계          최적화 후        │
│  ─────────          ──────────       │
│  월 보험료: 78만원  → 56만원         │
│  보장 공백: 3건     → 0건            │
│  중복 가입: 2건     → 해소           │
│                    절감: 월 22만원   │
└─────────────────────────────────────┘
```
- 배경: 오프화이트 / 좌측: 레드톤 / 우측: 그린·오렌지톤
- 하단에 반드시 "실제 고객 사례 (익명)" 표기

#### 2. 막대·꺾은선 그래프
- 색상: Primary 블루(현재) vs Accent 오렌지(최적화)
- 그리드 최소화, 데이터 라벨 직접 표기
- 범례는 차트 내부 직접 레이블 (우측 범례 박스 금지)

#### 3. 현금흐름 시뮬레이션 장표
- X축: 나이 (현재~85세), Y축: 월 수령액(만원)
- 구간 색상: 공백 구간(레드), 수령 구간(그린), 목표선(점선 오렌지)

#### 4. 손글씨 해설 레이어
- 실제 손글씨 또는 손글씨 폰트 (예: 나눔손글씨 펜, Gaegu)
- 컬러: 딥 네이비 또는 다크 레드
- 그래프·표 위에 오버레이로 "이 구간이 문제입니다 ↑" 식 주석

## 채널별 디자인 스펙

### 인스타그램 — 카드뉴스
| 항목 | 스펙 |
|------|------|
| 사이즈 | 1080 × 1080px (정사각) / 1080 × 1350px (세로) |
| 슬라이드 수 | 5~8장 |
| 1번 슬라이드 | 후킹 질문 + 숫자 1개 (크게) |
| 2~6번 슬라이드 | 데이터·표·그래프 설명 |
| 마지막 슬라이드 | CTA — "카톡 채널에서 증권 진단 신청" |
| 폰트 최소 크기 | 22px 이상 (모바일 가독성) |

### 인스타그램 — 릴스/숏폼
| 항목 | 스펙 |
|------|------|
| 사이즈 | 1080 × 1920px (9:16) |
| 형식 | 화면녹화 + 보이스오버 OR 손글씨 풀이 영상 |
| 길이 | 30~60초 |
| 자막 | 필수 (키워드 강조는 노란 하이라이트 배경) |
| 얼굴 노출 | 없음 — 화면·손·그래프만 |

### 블로그·네이버
| 항목 | 스펙 |
|------|------|
| 대표 이미지 | 1200 × 630px, 제목+핵심 수치 |
| 본문 삽입 표 | 배경 줄무늬 (#E8ECF0), 헤더 딥 네이비 |
| 인포그래픽 | 가로 전체 너비, 최대 800px |
| 강조 박스 | 테두리 2px 블루, 배경 `#EBF4FF` |

### 유튜브
| 항목 | 스펙 |
|------|------|
| 썸네일 | 1280 × 720px |
| 썸네일 구성 | 큰 숫자 + 질문형 텍스트 + 브랜드 컬러 배경 |
| 영상 형식 | 화면 캡처 + 음성 해설 (얼굴 X) |
| 하단 자막 바 | 딥 네이비 배경, 흰 텍스트 |
| 길이 | 10~15분 (분석 콘텐츠), 3~5분 (개념 정리) |

| 항목 | 스펙 |
|------|------|
| 대표 이미지 | 정사각형, 브랜드 컬러 배경 + 로고/슬로건 |
| 메시지 이미지 | 800 × 400px |
| 피드 포스팅 | 블로그 요약 + 핵심 수치 1개 + CTA 버튼 |

## 레이아웃 원칙

### 여백 (White Space)
- 정보가 많을수록 여백을 더 확보 — 빽빽한 표는 신뢰를 떨어뜨림
- 카드 내부 패딩: 최소 24px

### 정렬
- 숫자 컬럼: 항상 우측 정렬
- 텍스트: 좌측 정렬 (중앙정렬은 제목·강조문구만)

### 아이콘·일러스트
- 플랫 스타일, 라인 아이콘 (3D·과장된 일러스트 금지)
- 색상: 브랜드 컬러 팔레트 내에서만 사용
- 인물 일러스트 사용 시: 실루엣 또는 아이콘 형태만

## 브랜드 적용 금지 사항

- 그라디언트 남발 (포인트 1곳에만 허용)
- 3가지 이상 색상 혼용 (팔레트 외 색상 사용 금지)
- 손글씨와 고딕 폰트를 같은 계층에서 혼용
- 저해상도 스톡 이미지 (특히 악수·웃는 가족 사진)
- 보험사 로고·CI 무단 사용
